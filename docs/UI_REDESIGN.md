# 성적분석ON UI 재구성 (2026-09-14)

## 왜 바꾸나
1단계 화면은 생기부ON의 "사이드바를 순서대로 따라가는" 파이프라인 구조였다. 성적 분석은 파이프라인이 아니라
**사람(학급·학생)을 중심으로 여러 자료를 한 화면에서 겹쳐 보는 일**이다. 대시보드 초안(`_대시보드초안/`)이 이미 그 방향
(학급 한눈에 → 학생 상담 리포트 → 진학 참고선)을 잡았으므로, 그 정보 구조를 앱에 옮기고 우리 계산 원칙(등급 연산 금지,
백분위·석차백분율 기준, 교사용/학생용 분리)을 그 위에 얹는다.

## 정보 구조 (역할 기준 6개)
| 메뉴 | 누가 | 무엇을 |
|---|---|---|
| **학급** (홈) | 담임 | 학급 한눈에: 타일, 학생별 표(주요교과·전과목·교내 위치·성취도 A→E·직전 대비·입학 대비·눈여겨볼 점), 등급 분포, 교과 균형 레이더(반 vs 학년), 먼저 만나 볼 학생 |
| **학생** | 담임·상담 | 상담 리포트 한 장: 태그, KPI, 레이더, 과목 표, 교과별 추이, 내신 vs 모의 자, 가채점, 입학 대비, 상담 메모, 진학 참고(4대학 산식) → PDF/엑셀 |
| **과목** | 교과 담당 | 과목별 성취 분포(A~E), 등급 분포, 반별 비교, 학생 목록 |
| **학년·학교** | 교육정보부 | 스펙 L0~L7: 학교 리포트, 환율표, 스크리닝, 문항, 종단, 품질 검증, 전처리 (기존 화면을 하위 탭으로) |
| **진학** | 진학부·담임 | 4대학 성취도 산식, 춘고 3개년 수시 결과(대학·전형유형별 합격자 등급 범위), 강원 지역 대학별 지원·합격 범위, 참고선 편집 |
| **데이터** | 관리자 | 명단, 가져오기(나이스 교과학습발달상황 다중 파일 포함), 현황, 설정 |

상단 바에 **학년도·학년·반·학기** 공통 선택과 **학생 검색**(이름·학번)을 두고, 모든 화면이 같은 맥락을 본다.

## 계산 원칙 (대시보드 초안과의 차이)
- 등급 평균(주요교과·전과목)은 **표시용**. 교내 위치·직전 대비·입학 대비는 **석차백분율 환산값**으로 계산한다
  (5등급 → 누적 컷 구간 중앙값 5/22/50/78/95%, 학점 가중, 동점은 원점수−평균 편차로).
- 직전 대비는 "교내 위치 변화"이지 성장이 아니다. 성장은 모의고사 전국 백분위로만 말한다.
- 9등급 환산은 석차백분율을 9등급 컷에 얹은 표시용 값. 3개년 입결(9등급제 시절)과 맞댈 때만 쓴다.
- 잔차·회귀·확률은 학생 화면에 나오지 않는다. AI 분석은 보류(보낼 JSON 미리보기까지만).

## 데이터 추가
- 나이스 교과학습발달상황(`download-*.xlsx`, 반별 1파일): 학년/학기/교과/과목/학점/원점수·평균/성취도/분포비율/석차등급/수강자수. 성취도 3단계·이수 과목은 별도 블록.
- 편제표(공통/일반/진로/융합) → `SubjectCatalog`
- 고2 학력평가 3·6월(2022개정 파일, 학번 5자리)
- 전학년 명렬표(1·2·3학년) + 학적변동 시트
- 수시 진학결과 2023~2025(춘고) → `AdmissionResult` (이름 제외, 학년도·반·번호만)
- 강원 지역 대학별 전형별 지원·합격 범위 → `RegionalAdmission`
- 참고선(대시보드 초안 seed) → `UnivReference` (편집 가능)
