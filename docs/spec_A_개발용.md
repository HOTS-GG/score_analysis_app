# A. 개발용 스펙 (원문)

당신은 한국 고등학교의 성적 데이터 분석 시스템을 설계·구현하는 개발자다.
아래 명세대로 프로그램을 만들어라.

## 0. 도메인 전제 — 이걸 어기면 결과가 전부 무효다

[준거 집단의 비대칭]
- 모의고사(학력평가) = 전국 준거. 전국 백분위/표준점수 제공.
- 반배치고사, 내신 = 교내 준거. 서열 정보만 있고 절대 위치 정보는 없다.
- 모평은 교내 서열로 "내려올 수" 있으나, 교내 지표는 전국으로 "올라갈 수 없다".
- 따라서: 서로 다른 준거의 지표를 비교할 때는 반드시 교내 석차백분율로 통일한다. 전국 좌표가 필요한 계산에는 모평만 사용한다.

[등급 사용 금지 규칙]
- 등급끼리 직접 빼는 연산을 절대 하지 마라.
- 2025학년도 입학생부터 고교 내신은 5등급제(1등급 10%, 2등급 누적 34%, 3등급 누적 66%, 4등급 누적 90%, 5등급 100%)이고, 학력평가/수능은 9등급제(4/11/23/40/60/77/89/96% 누적)다. 칸 수가 달라 비교 불가.
- 모든 비교·연산은 백분위 또는 석차백분율로 수행하고, 등급은 출력 표시용으로만 쓴다.

[성장 측정의 원칙]
- 개인의 절대적 성장을 잴 수 있는 것은 모평 전국 백분위(또는 표준점수)뿐이다.
- 내신 등급의 시계열 변화를 성장 지표로 사용하지 마라. 집단 상대평가이며 학기마다 수강 집단이 바뀐다.
- 원점수로 회차 간 비교를 하지 마라. 시험 난이도가 다르다.

[최상위권 처리]
- 백분위는 상위권에서 천장 효과가 있다(백분위 99 안에 표준점수 130~145가 섞임).
- 표준점수가 있으면 상위 4% 학생은 표준점수 기준으로 추적하라.

## 1. 입력 데이터 스키마

student_id(익명 ID), grade_year(학년도), cohort(입학연도), class_no(반)

[입학 시점] mid_school_score, placement_raw(과목별), placement_rank
[모의고사] 회차(3/6/9/11월) × 과목별: raw, std, pct, grade9, 결시 여부, 무응답 문항 수
[내신] 학기 × 과목별: achievement(A~E), grade5, raw, subject_mean, subject_sd, enrolled_n, written/performance
[문항 단위] item_no, our_correct_rate, national_correct_rate, answer_distribution
[보조] 출결(지각/결과/결석 월별), 과제 제출률

※ 실제 파일은 컬럼명이 제각각이다. 컬럼 매핑을 사용자에게 확인받는 단계를 반드시 넣어라.
※ 어떤 항목이 없어도 나머지는 계산되도록 설계하라. 없는 지표는 "데이터 없음"으로 표시.

## 2. 전처리

1) 결측: 미응시를 0점으로 치환 금지. 반드시 결측 처리.
2) 분석 대상: 해당 회차 응시자. 추이 분석은 "3회 중 2회 이상 응시자".
3) 성실도 필터 — 무응답 ≥ 20%, 후반부 5문항 이상 동일 선지 연속, 전국 정답률 70%↑ 문항 극단 오답 → "성실 응시 의심" 플래그. 학교 단위 통계는 [전체]/[성실 응시자만] 두 버전.
4) 제외자(전학·자퇴 등)는 인원과 사유를 로그로 남긴다(생존 편향 기록).
5) 백분위 0 또는 100은 z 변환 시 오류. 0.5 / 99.5로 클리핑.

## 3. 계산 파이프라인

L0 학교 레벨(모평만): z_nat = Φ⁻¹(pct/100), mu = mean, sigma = sd, skew (|skew| ≥ 0.5 경고 → L2 등백분위)
L1 교내 위치: in_pct = RANK.AVG/N*100, z_in = Φ⁻¹(1 − in_pct/100). 모평 백분위도 교내 석차백분율로 변환.
L2 환율표: 방법1 모수적(z_nat_hat = mu + sigma·z_in), 방법2 등백분위(5~10% 구간별 중앙값·사분위). 둘 다 산출·차이 보고. N ≥ 200이면 방법2 기본. 상수 오프셋 보정 금지.
L3 개인 지표: position, delta(3→6, 6→9, 3→9), slope, volatility, subject_gap, consistency(내신 교내석차% − 모평 교내석차%), achievement_x_grade, written_vs_perf, cutline_margin(≤3 경계선), top_tier_track(상위 4% 표준점수)
L4 부가가치: x = 입학 환산(100 − 반배치 석차백분율, 고입내신과 합성), y = 회차 전국 z. 단순회귀 → residual, z_resid. 회차별 3개. 세 잔차 부호 일관 시에만 판정. r < 0.4 보류, N < 100 계산 안 함.
L5 문항: item_gap(−15%p 이하 집중 구간), 오답 40% 이상 선지 집중 → 공통 오개념, 난이도대 3구간(70%↑ / 30~70 / 30%↓) 프로파일 → 실수·시간관리형 / 상위 실력, 후반부 급락 → 시간 부족
L6 종단: 전이행렬(고1 3월 × 고3 9월, 셀 < 10 표본 부족, 등급 이동 + 백분위 변화폭, 고3은 회차 내 상대 이동), 상승군 vs 하락군 고1 특성 비교 → 갈림길 지표
L7 학교 성과: mu/sigma 3→6→9 및 전년 동회차, 등급 분포, 잔차 꼬리

## 4. 플래그 규칙 (설정 파일로 조정)
연속 하락 Δ(3→6) ≤ −7 AND Δ(6→9) ≤ −7 / 급락 Δ ≤ −15 / 과목 불균형 ≥ 30 / 기복 ≥ 15 / 유형 불일치 |consistency| ≥ 20 / 저평가 성장 z_resid ≥ +1 2회 이상 / 조용한 하락 z_resid ≤ −1 인데 등급 유지 / 적응 실패 반배치 상위 30% → 9월 교내 하위 50% / 집단 착시 성취도 C~E 인데 내신 1~2등급 / 경계선 cutline ≤ 3 / 실수형 쉬운 문항 실점 ≥ 40% / 성실도 의심

## 5. 출력물
1) 학교 리포트 2) 학년 스크리닝 명단 3) 학생 카드(백분위 3점 추이 / 과목별 막대 / 성취도×등급 / 4분면) 4) 원자료 + 파생지표
[학생 카드에 넣지 말 것] 잔차, z_resid, 회귀 예측값, 전이행렬 확률. 비교 기준은 "3월의 자기 자신".
[4분면] 가로 = 내신 교내 석차백분율, 세로 = 모평 전국 백분위. ①내신↑모평↑ ②내신↑모평↓ ③내신↓모평↑ ④내신↓모평↓. 3→9월 변화 화살표.

## 6. 금지 사항
인과 표현 금지 / 내신 기준 전국 위치 점추정 금지(구간으로) / 교사·학급 평가 집계 금지 / "유의미"만 쓰지 말고 효과크기·신뢰구간 / 실명은 분석 테이블에 넣지 않음

## 7. 품질 검증
홀수반/짝수반 안정성 / 전년도 회귀식 백테스트(MAE, ±10 적중률) / 모든 지표에 N (N < 30 경고) / 단위 테스트(등급-백분위 변환, 동점 순위, 결측 전파, 클리핑 경계)
